# [LeafletViewer](https://kotdijian.github.io/JASOSR/01LeafletViewer/)
[*Leaflet*](https://leafletjs.com/)を用いたCSV遺跡地図データの簡易表示ビューワーです。

*Leaflet*は、インタラクティブ地図のためのオープンソースJavaScriptライブラリです。

読み込ませるCSVファイルを変更する場合は、139行目の '<ins>const CSV_URL = "./13Tokyo/13Tokyo_total.csv";</ins>'のダブルクオーテーション内のパスを変更してください。
